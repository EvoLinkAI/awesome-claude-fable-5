# Contributing

This repository curates high-signal Claude Fable 5 use cases from public sources.

## Case Requirements

New cases should include:

- Original source link
- Creator handle and profile link
- Evidence type: `Demo`, `Tutorial`, `Evaluation`, or `Integration`
- Quality tier: `⭐⭐⭐ High`, `⭐⭐ Medium`, or `⭐ Low`
- Short English summary that paraphrases the source
- Date in `YYYY-MM-DD` format

## Quality Tiers

- `⭐⭐⭐ High`: reproducible workflow, prompt, benchmark, full flow, concrete integration steps, or strong teaching value
- `⭐⭐ Medium`: real usage signal with lighter implementation detail
- `⭐ Low`: thin but valid signal

## Attribution

Do not copy long source text. Summarize the evidence, link to the original post, and credit the creator.

If a creator asks for a correction or removal, update the case promptly.
